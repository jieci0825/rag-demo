# 下一版本迭代计划

## 背景

当前版本优先完成系统上线，索引治理阶段仅实现去重与清洗。

Hierarchical Indexing、增量更新、多知识库和权限控制暂不纳入当前版本，
计划在下一版本补充。

## 下一版本内容

### 多知识库

当前版本仅提供一个默认知识库，下一版本需要支持创建和管理多个知识库。

下一版本需要完成：

- 支持多个知识库。
- 明确文档与知识库的归属关系。
- 支持按知识库管理和检索文档。
- 补充对应测试。

### RBAC 权限模型

下一版本引入基于角色的访问控制，对系统资源的操作权限进行管理。

下一版本需要完成：

- 建立用户、角色和权限之间的关系。
- 限制不同角色可执行的操作。
- 在服务端接口中校验访问权限。
- 补充对应测试。

### 文档权限

为文档增加权限限制，避免用户检索或访问无权查看的文档。

下一版本需要完成：

- 为文档记录访问权限。
- 在文档查询和管理接口中执行权限校验。
- 在检索阶段过滤无权访问的文档及 chunks。
- 补充对应测试。

### Hierarchical Indexing

为文档建立层级索引，解决细粒度检索与完整上下文之间的平衡问题。

下一版本需要完成：

- 明确索引层级及父子关系。
- 实现层级索引的生成与存储。
- 实现基于层级关系的检索与上下文返回。
- 补充对应测试。

### 增量更新

文档内容发生变化时，仅更新受影响的索引，避免每次重新构建全部索引。

下一版本需要完成：

- 识别文档新增、修改和删除。
- 更新发生变化的 chunks 及其 embeddings。
- 删除已经失效的 chunks。
- 保证重复执行更新时不会产生重复数据。
- 补充对应测试。
